# Accessibility Statement

We are committed to making `gcr-top` accessible and usable for everyone, including users with disabilities and those using assistive technologies.

## Features & Design Principles

- **Keyboard Navigation:** gcr-top is fully navigable via standard keyboard inputs (for example, arrow keys, vim-keys, or specific shortcuts shown in-prompt). No mouse interaction is required.
- *Tool & Terminal Compatibility:** The user interface is built using standard ASCII/Unicode terminal primitives to ensure compatibility across modern terminal emulators.
- *Color & Contrast:** While we strive for sufficient color contrast, the appearance may depend on your terminal color palette. We recommend using a high-contrast terminal theme if you have low vision or color vision deficiencies.

## Reporting Accessibility Issues

If you encounter an accessibility barrier, such as a lack of screen-reader compatibility, poor contrast, or inaccessible keyboard layouts, please let us know:

1. Open an issue on [GitHub](https://github.com/struyf/gcr-top/issues).
2. Use the tag `accessibility` in your title or labels.
2. Describe the assistive tool you are using and the exact behavior or obstacle you faced.

We will prioritize and address accessibility feedback promptly.
