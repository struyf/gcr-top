# Security Policy

## Supported Versions

We actively provide security updates and patches for the following versions of `gcr-top`:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `gcr-top` seriously. If you discover a security vulnerability, please do **not** report it in a public issue.

Instead, please report vulnerabilities via one of the following methods:

1. **GitHub Security Advisory (Preferred):**  
   Open a private advisory report under the **Security** tab of this repository (`Security` → `Advisories` → `Report a vulnerability`).
2. **Direct Contact:**  
   If you are unable to use GitHub Security Advisories, please contact the maintainer directly via GitHub or the contact details provided in the profile.

### What to Expect

* **Initial Response:** You will receive an acknowledgment of your report within 48 hours.
* **Assessment & Fix:** We will evaluate the report, verify the impact, and work on a fix in a private branch.
* **Disclosure:** Once a patch is released, we will publish a security release and publicly credit you (if desired).
